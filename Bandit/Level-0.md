# Bandit Level 0

## Objective
Connect to the Bandit game server using SSH.

## Command Used

```bash
ssh bandit0@bandit.labs.overthewire.org -p 2220
```

## What I Learned

- **SSH (Secure Shell):** A protocol used to securely access a remote system.
- **Username:** `bandit0` is the account used to log in.
- **Hostname:** `bandit.labs.overthewire.org` is the remote server.
- **Port:** `-p 2220` specifies the port used by the Bandit SSH service.

## Result
Successfully connected to the Bandit server and accessed the remote terminal.
